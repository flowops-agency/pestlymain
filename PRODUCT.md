# Product

## Register

brand

## Users

Data engineers, analytics engineers, data stewards, and compliance leads at mid-to-large companies who deal with messy incoming files (CSV, XML, Parquet, JSON) from multiple sources. Their context: shared folders, Slack channels, and email inboxes where files accumulate with no schema contract, no lineage, and no quality check before landing in production.

## Product Purpose

Data Trust Accelerator turns chaotic file ingestion into a governed, reviewable pipeline. Teams scan incoming files, quarantine risky rows (PII, null floods, schema drift), resolve flagged issues through a review queue, and publish certified data products with auto-generated governance artifacts (schema contract, audit log, lineage, compliance report).

Success: a data team that ships trusted datasets with zero surprises — every file has a reviewable run, every dataset has a verifiable trust score, every decision is logged.

## Brand Personality

Bold, modern, operational. Direct copy with no marketing fluff. Confident typography. High contrast. One accent color (emerald) on a near-monochrome base. Feels like a serious tool for teams that handle production data, not a splashy SaaS brochure.

## Anti-references

- Generic AI-purple gradients and glassmorphism
- Fake dashboard rectangles with glowing charts
- Three identical feature cards in a row
- Em dashes in copy
- Decorative status dots that don't correspond to real states
- Scroll cues, version labels in hero
- Side-stripe borders, gradient text
- Eyebrow tags (tiny uppercase "ABOUT" / "PROCESS" / "FEATURES") on every section
- Numbered section markers (01 / 02 / 03) as default scaffolding

## Design Principles

1. **Operational first, not marketing.** Every visual element should serve clarity and trust, not decoration. The page communicates what the tool does, concretely.

2. **High contrast, low noise.** Near-black text on off-white background. One accent color. No gradients, no blurs, no glass. Information density is earned through whitespace, not decoration.

3. **Show the work.** Instead of generic feature descriptions, the page shows concrete artifacts: a scan results table with quarantined rows, a review queue with real states, a list of governance artifacts. The product IS the visual.

4. **Confident restraint.** Big typography, generous whitespace, but nothing gratuitous. Every section earns its place. Copy is direct and terse.

5. **One accent, consistent system.** Emerald `#0f7a4f` is the single accent. Amber and red are semantic states (review queue warnings, quarantined rows), not decorative colors. 12px radius for panels, 999px for buttons.

## Accessibility & Inclusion

- WCAG AA minimum (4.5:1 body text contrast, 3:1 large text)
- Respect `prefers-reduced-motion` — animations only on transform and opacity
- Skip-to-content link at page top
- Focus-visible ring on all interactive elements
- Touch targets at least 44x44px on mobile
